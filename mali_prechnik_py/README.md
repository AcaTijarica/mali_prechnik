# Мали пречник за PC

Ово је PySide6 уредничко приложеније за попуњавање службене базе `Малог пречника`
на рачунару. Намена му је да се нове туђице, порекло туђице, додатак и
српскословенски предлози уносе кроз обичан GUI, без ручног писања JSON заграда,
зареза и наводника.

Подразумевано чита и чува:

```text
database/input/official_entries.json
```

## Покретање

Из корена Android пројекта:

```powershell
python -m pip install -r mali_prechnik_py/requirements.txt
python mali_prechnik_py/app.py
```

У PyCharm-у је довољно отворити овај пројекат, одабрати Python interpreter у
коме је инсталиран `PySide6`, па покренути:

```text
mali_prechnik_py/app.py
```

## Шта апликација ради

- претрага у смеру `туђица -> српслв`;
- претрага у смеру `српслв -> туђица`;
- претрага старих речи преко старе речи или њене сличнозначнице;
- списак туђица груписан по почетном слову;
- списак старих речи груписан по почетном слову;
- додавање нове туђице;
- измена постојеће туђице;
- уклањање туђице;
- додавање, измена и уклањање старих речи;
- више српскословенских предлога за једну туђицу;
- померање српскословенских предлога дугмадима `^` и `v`; апликација из тог
  редоследа сама уписује унутрашњу тежину предлога;
- чување исправног `official_entries.json`;
- увоз из постојећег JSON или SQLite `.db` фајла;
- слање предлога измене у Firestore;
- слање нове речи као предлога у Firestore;
- учитавање предлога за гласање, гласање, пријава и локално блокирање
  предлагача;
- покретање грађења Android seed базе;
- покретање грађења A5 PDF мини речника.

Онлајн део ради само ако локално постоји:

```text
app/google-services.json
```

Тај фајл се не чува у git-у. Ако га нема, локално уређивање JSON базе и даље
ради, али Firestore гласање и предлагање неће бити доступни.

## Уреднички ток

1. Покренути PC апликацију.
2. Отворити `Додавање/Измена`.
3. Унети туђицу, порекло туђице, додатак и предлоге. Предлоге поређати
   дугмадима `^` и `v`.
4. Кликнути `Сачувај реч у JSON`.
5. Када је унос завршен, отворити `Складиште`.
6. Кликнути `Направи Android seed DB/JSON`.

Тиме се освежавају:

```text
database/generated/prechnik_seed.db
database/generated/prechnik_seed.json
app/src/main/assets/prechnik_seed.db
app/src/main/assets/prechnik_seed.json
```

После тога треба поново изградити Android апликацију.

Ако је `official_entries.json` раније ручно уређиван и има сувишан зарез пре
краја низа или објекта, PC уредник ће покушати да га прочита. При првом чувању
кроз GUI фајл се поново исписује као исправан JSON.

## Windows EXE

Зависности за изградњу самосталног Windows издања:

```powershell
python -m pip install -r mali_prechnik_py/requirements-build.txt
```

Из корена Android пројекта покренути:

```powershell
.\mali_prechnik_py\build_windows.ps1 -Version "1.0.0"
```

Готов фајл биће направљен на:

```text
mali_prechnik_py/build/release/mali-precnik-1.0.0-windows-x64.exe
```

Фасцикла `build` је генерисани излаз и не прати се у git-у. На GitHub Release
поставља се само готов `.exe`. Упакована верзија при првом покретању копира
службено складиште у `%LOCALAPPDATA%\MaliPrechnik\official_entries.json`, где
се даље чувају корисникове измене.
