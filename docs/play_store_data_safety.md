# Play Store Data safety подсетник

Овај фајл је подсетник за попуњавање Google Play Console `Data safety`
обрасца. Не слати апликацију као да „не прикупља податке”, јер онлајн део
апликације користи Firebase Anonymous Auth и Cloud Firestore.

## Подаци које треба пријавити

У Data safety делу треба пријавити најмање:

- anonymous Firebase user id корисника који шаље предлог, глас или пријаву;
- anonymous Firebase user id предлагача чији је предлог пријављен;
- предлоге које корисник шаље;
- гласове корисника;
- пријаве предлога и предлагача.

## Сврха обраде

Сврхе су:

- app functionality;
- moderation/safety;
- abuse prevention.

## Шта апликација не ради

За ову верзију апликације навести:

- подаци се не продају;
- нема реклама;
- нема аналитике;
- нема правих корисничких налога са именом, лозинком или ел. поштом;
- предлози не постају јавно видљиви док их уредник не одобри.
